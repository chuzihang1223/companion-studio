# MCP 与 Skills 安全边界

## 权限与低信任数据

模型、MCP 工具描述/注解、结果、Resources、Prompts 和 Skill 内容都不能修改本地策略。
外部工具默认禁用且为高风险，不因 `read_file` 名称或 readOnly 注解自动信任。
用户主动审阅的风险标签只决定恢复资格，不是 OS 沙箱或行为证明。

内置工具仍使用原 ToolRegistry 和执行器。MCP 参数经受限 JSON Schema 校验，执行前重新发现
工具并比对 Schema/身份/副作用类别；变更后禁用工具，旧计划不能套用新定义。
审批经现有 PermissionPolicyEngine / TrustedActionStore；MCP 的单次审批还要求本机控制接口
形成当前任务、调用、Schema、参数摘要绑定。普通聊天 HTTP 的 approved_ids 不能单独授权。

会话/任务授权仅对经审阅只读工具开放；关闭任务清理任务与单次授权，重启不恢复这些临时授权。
撤销、禁用、删除、断线和内容哈希变化在下次执行前重新检查。并发会话不共享无关授权。

## 本地进程

只启动用户明确填写并确认的现有 EXE，无 shell、无自动安装。收缩环境，不继承模型、语音、
代理和账号配置；必要环境值单独加密保存。管道帧、输入参数、输出、超时均有上限。
使用自有 Windows Job 管理已启动子进程及后代；不按同名 EXE 批量结束进程。

外部程序仍以当前账号运行。权限 UI 无法阻止恶意程序直接访问系统；这不是完整权限沙箱。
创建进程至附加 Job 之间存在短暂窗口，不能声称任何硬件/系统崩溃都绝无遗留。

## 网络

远程要求 HTTPS，拒绝 URL 凭据、查询字符串、跳转和压缩响应；不继承系统代理。
每次解析只接受全为公网的地址，再将连接固定到实际 IP，同时保留原 TLS SNI 与 Host，
避免验证一次 DNS 后由第二次解析转向本地。固定端点与 GET/POST/DELETE 白名单限制传输。
本机开发例外显式开启，限字面回环地址并拒绝应用后端端口；不是任意私网访问开关。
TLS 行为来自 SDK 依赖 httpx2；仅本机 HTTP / 合成传输不等于任意远程服务已验收。

## 凭据与记录

Windows safeStorage 保存密文，完整配置摘要绑定凭据。Token 只留本机主进程/后端内存及
指定 Server；不在模型 Schema、SQLite、Trace、评测、导出模板、Git 或安装包中保存。
外部 SDK 原始日志不转入应用日志，诊断使用固定错误码和计数；stderr 仅排空和计数。
工具结果按已知凭据值及常见敏感字段二次处理，但不是对任意未知私人内容的匿名化服务。

Trace 只保存受控 UUID、摘要、状态和计数；默认丢弃提示词、私有文件正文、Token、路径、
URL、环境值及 Server 自由文本。Evaluation 使用独立空白档案与审计过的合成服务器。

## Skills

只导入目录，不解压归档；因此压缩炸弹与 Zip 路径不会进入解压执行路径。
拒绝路径穿越、NTFS ADS、重解析链接、凭据目录、过大文件和 YAML 对象/别名/重复键。
导入保存不可变快照和逐文件摘要，更新不会覆盖第三方同名或自建 Skill。
导入、启用、查看及选中都不执行 scripts；本版没有 Skill 脚本运行按钮。
参考文件仅在当前 Skill 已选中时可由受控只读工具读取；脚本不能借此执行。

高风险外部状态未知时进入 NEEDS_REVIEW，不能自动重发消息、删除文件或提交表单。
安全扫描通过只代表已定义范围通过，不能保证零漏洞或第三方软件无恶意行为。
