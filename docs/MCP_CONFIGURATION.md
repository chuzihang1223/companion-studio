# MCP 配置与使用

本功能属于独立审核分支，已公开的 v0.1.2 不包含它。

## 添加服务器

打开「设置 → MCP & Skills → MCP Servers」。新增、填写、保存配置后仍未启动连接。
勾选启用，点击「连接／重新连接／测试」，审阅 Windows 原生确认框后才运行程序或连接端点。

- stdio：填写现有 `.exe` 的绝对路径和 JSON 字符串数组参数，例如 `[]`。
  不接受 cmd、PowerShell、Shell 命令或自动安装命令。第三方程序及运行时需要用户自行准备。
- HTTP：使用准确 HTTPS MCP URL。重定向、代理、URL 内凭据和查询参数均拒绝。
  开发例外仅接受用户明确开启的 `127.0.0.1` / `::1`，禁止本应用后端端口。
- 超时：连接 2–30 秒，工具 0.2–60 秒；最多 3 次连接建立尝试，鉴权失败停止。
- 协议：推荐自动探测；可选择 `2026-07-28` 或 SDK 旧式握手兼容模式。

所有工具最初禁用、高风险。查看描述与 Schema，自行确认真实行为后启用；Server 注解不降低风险。
每次执行都走原 Runtime 和权限策略。服务器离线、工具被禁用、Schema 改变或参数错误时拒绝调用。
会话/任务范围授权只适用于经审阅只读工具，绑定工具身份、Schema 和完全相同参数；
高风险操作只能单次确认。普通 HTTP 的 `approved_ids` 不构成 MCP 授权。

## 凭据

Bearer Token 与必要环境变量值在凭据栏录入，由 Electron Windows 安全存储加密。
SQLite 只保存环境变量名称和凭据存在引用；解密值仅传给对应后端内存和该服务器。
不在参数数组中填密钥。不允许 PATH、解释器加载钩子或代理变量。
凭据绑定完整配置摘要；修改配置后需重新录入，旧加密记录不被转送给新端点。
前端不能读取已保存值。当前不提供 OAuth 登录、刷新或自动打开授权网站。

## 工作模式

连接后输入明确任务，例如「使用 MCP echo 返回一段测试文字」。需要支持 Tool Calling
的模型才能选取外部工具；默认测试使用本地合成模型，不触发真实费用。
从工作流查看所选 Skill、工具来源、参数和授权范围；从 Trace 查看实际调用及固定错误码。
协议成功、有效结果和用户目标完成分别记录。通用 MCP 尚无业务专用外部状态核验，
不能仅凭 Server 的成功文字把目标标为已验证。

Resources 和 Prompts 可列出、手动授权读取并预览；只接受该 Server 当前列表中的身份。
返回内容不自动执行。可手动把最多 3000 字的预览片段加入输入框，发送前自行审阅。
不支持的能力显示空列表，工具连接不因此失败。

## 随附安全测试服务器

安装版后端支持 `companion-backend.exe --mcp-demo`，只操作其独立工作目录内的固定合成文件。
它不是 Python CLI，不用于运行任意脚本。可把本安装的后端 EXE 路径作为 stdio 配置，参数
`["--mcp-demo"]`。安装目录中的实际路径由用户选择，不写死开发者机器路径。

源码调试可用本项目虚拟环境 Python，参数填写 `backend/run.py` 的实际绝对路径及 `--mcp-demo`。
HTTP 测试可在独立终端运行：

```powershell
.\.venv\Scripts\python.exe -B backend\run.py --mcp-demo http 8795
```

随后配置 `http://127.0.0.1:8795/mcp`，勾选本机开发例外。终端启动的 HTTP Server 归终端所有；
MCP Client 断开不会关闭它。日常启动应用不会自动运行测试服务器。

脱敏配置模板不带凭据、环境变量值、可执行文件私有路径或参数；需手动补全并确认，不能自动启动。
