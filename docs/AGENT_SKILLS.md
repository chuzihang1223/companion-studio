# Agent Skills 使用

「设置 → MCP & Skills → Agent Skills」支持预览导入文件夹、创建、自建编辑、启用/禁用、
查看 SKILL.md/文件清单、更新相同记录、导出自建 Skill 和删除注册。每项操作有结果反馈。
不支持压缩包、不下载第三方文件、不自动安装依赖或运行脚本。

导入前先校验并显示内容/文件摘要；主进程只接受用户通过文件选择器选中的目录，导入票据
限本窗口、一次使用、5 分钟过期。后端再次核对预览摘要，目录变更后必须重新预览。
同名冲突拒绝；更新生成新快照并禁用，需要用户重新启用。删除保留原始文件和本地快照。

## 按需使用

在工作任务明确写 `$project-review` 或 `skill:project-review`。也可由名称/描述的确定性
相关性匹配，先显式名称、再相关分数、最后稳定身份排序；只选一个，避免静默混合指令。
工作流和 Trace 显示实际选中的 Skill。普通 Chat 不自动加载工作 Skill。

平时只读元数据；匹配后才读取主说明。确有需要时模型可用 `skill.read_reference` 读取当前
选中的 Skill 的 references/ 文本，逐文件校验摘要，不能访问其他 Skill 或执行脚本。
缺少 required_tools/能力时停止工具计划并提示，不自动添加 Server。
执行期间每步复核启用状态与内容摘要，禁用或更新后旧计划不能继续使用它。

主说明作为低信任用户级参考加入上下文，不进入系统消息，不授予权限。
输入、保存和输出仍受原文件路径、权限、工作区、取消和预算约束。

示例目录位于 `examples/agent-skills`：project-review、markdown-report、workspace-search。
它们是供 Companion Studio 用户导入的任务说明，不是 Codex 的开发技能，不继承开发账号权限。

## 当前限制

仅本地目录导入，最多 128 文件、总计 4 MB、单文件 1 MB；主说明与文本预览最多 32 KB。
脚本只能查看，不提供内置执行隔离或人工运行按钮。参考文件不会自动整目录上传。
命中率来自合成用例，不能代表任意第三方 Skill 的兼容性、可靠性或指令安全证明。
