# 托盘、通知与退出

工作模式 → 模块 → 定时任务。也可从系统托盘进入管理页。
默认关闭主窗口会完全退出，不暗中驻留。勾选“关闭窗口保持托盘运行”需主进程确认；
设置保存在该档案。明确启用后关闭窗口只隐藏，后端调度继续运行。

托盘包含打开主窗口、定时任务、暂停全部、恢复触发、最近执行结果、完全退出。
完全退出先停止调度与监控、中断自己拥有的任务，再关闭自有后端。
存储暂不可用时仍清理精确归属的内存协程。不会结束别的版本或按进程名批量杀进程。

不提供 Windows 登录自启，不写启动项、不安装 Windows 服务或系统任务。
电脑睡眠、关机、完全退出后无法定时运行；重新打开按用户选择的漏执行策略处理。
这不是 7×24 云服务。

本地通知只包含应用名、状态和时间，不包含任务名、聊天、路径、密钥或截图。
数据库先记录 PENDING；主进程先领取 ATTEMPTED 再请求原生显示。
SHOWN 仅表示 Electron 原生 show 事件，不证明用户已读；FAILED / UNAVAILABLE 如实保留。
崩溃后的 ATTEMPTED 状态可能未知，不无条件重发。Windows 通知设置可以屏蔽展示。
点击目标绑定 owner、schedule 和 occurrence；最近结果列表可打开精确历史。
活动原生对象最多保留 16，失败与退出清理，退出竞态不再创建新通知。
