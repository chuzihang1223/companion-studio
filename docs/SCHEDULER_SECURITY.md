# 调度权限边界

Schedule 只决定何时尝试。它不授予原工具权限、不修改 PermissionPolicy、不绕过
主进程令牌，不继承开发代理权限。管理页只列当前档案，工作会话数据按 owner 隔离。

保存绑定不可变已发布版本、输入哈希、依赖哈希、当前项目身份和模型目标哈希。
草稿变化不影响旧版本；被归档、失效依赖、MCP Schema 改变或 Skill 禁用会阻断派发。
模型目标摘要不包含明文密钥或 URL；日志只记录固定代码与随机 ID。

默认无人值守范围很窄：纯数据节点及当前权限仍允许的本地只读工具。
模型、外部 MCP、Skill、写入、应用控制和 Computer Use 需要每次明确确认启动。
主进程可信对话框展示计划、机会、固定版本、输入字段数量和模型风险，绑定不可变摘要。
同意仅对本次快照有效五分钟；之后仍需原工具按本次实际参数审批。
smart 模式也不能把调度同意变为未来所有工具的通行证。

Knowledge 后台只允许固定 keyword 搜索。Hybrid / Vector 可能外传至 Embedding，
因此包括整参数 `$ref` 和动态模式均保守阻断；本次同意也不会开启后台远程 Embedding。
普通前台 RAG 保持原能力。GroundedService 在异步准备完成后再次验证，再发送文本模型请求。

权限/版本/来源在节点、审批等待后以及实际 operation 和每次重试前重复检查。
暂停全部停止新触发与领取，不声称能撤回已发出的外部操作。
Computer Use 继续要求当前窗口授权、交互桌面、焦点与结果验证；锁屏/UAC 不可绕过。
默认无截图或上传，真实 Vision 仍为未测试。

测试用受控 Server、合成文本、空白档案，未访问私人账号或调用真实收费模型。
审计与独立对抗测试分别记录，无法核验的原生通知不标为用户收到。
