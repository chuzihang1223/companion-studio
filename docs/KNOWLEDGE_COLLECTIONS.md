# 知识库与目录授权

入口：侧栏「知识与记忆」，或工作模式 → 模块 →「本地知识与记忆」。
工作台只增加默认关闭的新模块，不改变原有拖拽、缩放、坐标、滚动或持久化版本。

1. 填写名称和说明，新建知识库。
2. 「选择并授权目录」通过主进程文件夹选择器确定范围，再原生确认。
3. 点击「增量索引」，观察进度及错误数；配置变化后重新索引。
4. 在当前会话勾选库，选择「仅授权本地检索」即可离线搜索。
5. 如果希望模型回答，另行「授权检索片段给当前模型」，再启用此会话 RAG。

没有默认根目录，也不自动扫描桌面、文档、下载、用户目录或整个磁盘。
通用助手与自定义角色的会话授权按 `conversation_id + character_id` 检查；
Work/Project 会话也必须单独选择，猜中库 ID 不代表获得访问权。

Collection 保存名称、说明、显式 roots、格式/排除策略、Embedding 模式、配置修订号、
索引版本、状态和时间；文档与片段数实时查询。最多 100 个库、每库 10 个根目录。
目录保存当时的设备/文件身份，后续读取重新核验。

默认忽略 `.git`、`node_modules`、`.venv`、`venv`、`__pycache__`、`build`、`dist`、
`cache`、`.cache` 等。界面可加排除 glob；受控配置接口也可修改格式、默认忽略名和 include glob。
路径安全与私密配置排除不因 glob 放宽。默认单文件 8 MiB、每库 2,000 文档、20,000 片段。

进行中的索引必须先取消/等待结束，才能改 roots、策略或删除库。修订号防止旧页面覆盖新设置。
删除知识库、移除 root 只清除索引和相关授权，不删除源文件。

受控请求示例（通常由桌面主进程构造）：

```json
{"name":"项目资料","description":"安装与代码说明"}
```

```json
{"conversation_id":"11111111-1111-4111-8111-111111111111","character_id":"assistant","collection_ids":["22222222-2222-4222-8222-222222222222"],"allow_model_transfer":false,"expected_targets":[]}
```

模型地址/名称热切换后旧传输授权失效；本地检索授权不会自动扩大到新模型或 MCP。

「文档与解析错误」按库分页显示相对路径、状态、大小、版本、索引时间和固定错误码，不展示或上传原文。
