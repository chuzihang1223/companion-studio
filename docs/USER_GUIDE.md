# Companion Studio 使用说明


## 0.2.0-router.1 本地候选：模型路由

1. 在设置 → API 中创建自己的模型预设，设置服务地址、模型和密钥；密钥只由主进程安全保存并交给后端。
2. 确认实际支持的文字、流式、工具、视觉、结构化能力，不根据模型名字猜测。
3. 展开智能模型路由。默认关闭；手动与模型职责模式保留指定选择，自动模式只用明确允许自动请求的模型。
4. 填写已知上下文容量；分别允许远程普通文字与文件/工具资料。知识库和截图授权仍单独确认。
5. 配置请求次数上限。价格未知不会视为免费；严格金额上限缺少可信输入计数时会拒绝请求。
6. 保存不会发出模型请求。新任务使用新配置，进行中的任务保持快照。刷新状态可查看真实样本与最近请求。

示例输入：`读取所选项目的说明文件并总结实际内容。` 输出先是待批准工具计划，批准后显示工具观察、
基于实际结果的回复及 Trace；模型错误或预算不足会显示明确状态，不能把 HTTP 成功当成任务完成。

普通聊天也可以不使用角色卡；角色管理支持用户自行导入/自定义，软件不附带第三方角色或音色。
语音默认不开麦。录音终句可以先校对再发送；系统 ASR 不提供 Partial Transcript，自动 Barge-in/AEC 尚未验收。
