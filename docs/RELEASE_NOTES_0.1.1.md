# Companion Studio 0.1.1

本版本完善工程质量与 Windows 安装包交付，保留已有聊天、角色管理和模块化工作台。

## 本次变化

- 为 Agent 规划、工具、权限、并发调度、验证与取消补充准确的中文说明和类型。
- 统一 Python / Electron / React 格式，建立 Ruff、ESLint、Prettier、TypeScript 检查。
- 补充架构、Agent Runtime、工具系统、工作台、开发及贡献文档。
- 隔离自动测试档案并阻止测试访问外部模型；增加排队、取消、并发与 URL 校验回归。
- 修复浏览器 URL 校验中 IPv4 映射 IPv6 私网地址遗漏。
- 增加 CI 与 tag 驱动的 Windows **草稿**发布流程，版本从项目配置读取，构建 metadata 写入 staging。
- 修复特定 Windows 程序目录下的沙箱文件读取兼容问题：安装时只给明确运行文件添加非继承读取权限，保留网页沙箱和用户资料权限。

## 安装与首次使用

下载 `Companion-Studio-0.1.1-Setup.exe` 和 `SHA256SUMS.txt`，核对 SHA256 后运行安装器。推荐把程序安装到可写的 `应用根目录\Release\installed`，首次启动创建独立 `UserData`。再次使用相同根目录可恢复档案，安装器不要求安装 Python 或 Node.js。

在 **设置 → API** 填写自己的 OpenAI-compatible 地址、模型和凭据。未配置模型也能打开界面；文字回复需要可用模型服务。新安装仅含通用助手和原创应用图标，可导入 JSON / PNG 角色卡或手工创建角色。

## 功能与限制

提供流式聊天、本地历史、多会话任务调度、权限控制、结果验证、模块化 Workbench、Windows 应用发现及本机工具。恢复机制在重启后标记中断任务，**尚无完整自动断点恢复**。

可选 Fish Audio、本地语音和 Codex 编码能力需要用户自行准备服务、模型或账号，服务可能计费。没有附带 API Key、声音 ID、第三方角色图片、参考音频、语音模型或用户记录。

音乐和桌面操作受已安装客户端、登录、桌面解锁与焦点影响，不保证所有系统环境和软件版本均成功。此安装器没有发行者数字签名，可能触发 Windows 的未知发行者提示；没有宣称 Windows 官方认证。第三方组件许可及对应源码随安装包保留，原创部分为 MIT。
