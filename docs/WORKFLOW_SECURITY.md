# 工作流安全边界

工作流和导入 JSON 是用户数据，不是可执行程序；模型、MCP、文件及 Skill 返回内容是低信任数据。
流程设计器不继承 Codex 开发账号权限，也不能修改应用权限模式、API 密钥和系统配置。

| 边界 | 实际控制 |
| --- | --- |
| 本机入口 | 主窗口身份检查、固定 IPC 操作、后端控制令牌；嵌入网页不能调用。 |
| 导入 | 原生选一个普通 JSON 文件、500 KB 限额、严格 Schema、新 Workflow UUID，不覆盖旧定义。 |
| 图执行 | DAG、类型、依赖、变量祖先作用域和预算校验；禁止 eval、任意动态代码节点。 |
| 项目 | 仅使用当前会话明确选择的项目，Run 固定目录；目录变化停止后续工具。沿用私密路径、链接和 NTFS 检查。 |
| 工具 | 原 ToolRegistry / 权限策略，本地重新算风险；参数全部解析后再确认。 |
| MCP | 原服务器、工具 ID、Schema 摘要、参数摘要和任务范围的精确授权；一般 approved_ids 无法代替 MCP grant。 |
| Skill | 当前启用、内容摘要及依赖复核；描述、allowed-tools 和脚本文件不授予权限。 |
| 人工审批 | 每次独立 UUID、节点执行 ID 和所有者；普通审批不提前批准下游工具。 |
| 版本 | 草稿 revision CAS；发布只新增版本，运行不可指向可变草稿。 |
| 恢复 | 原执行意图、核验与 RecoveryPolicy；不根据历史成功文字重复副作用。 |
| 输出 | 本地有界数据；文件、Trace、评测引用受归属检查；原 Trace 不存正文。 |

模型请求预算限制本应用 Provider 调用；原工具内部调用和安全重试也保留已有约束。
外部 MCP 程序、Python 脚本或用户配置的编码客户端可能自行访问网络/文件，宿主权限 UI 不是
OS 沙箱，宿主 Token 统计不能代替它们的费用统计。运行概览和高风险工具的逐次确认不能跳过。

本地 Run 数据保存用户明确提供的输入和有界输出，用于结果与续接；它们属于私人档案，不能
当作可公开源码、发布包或默认示例复制。导出工作流只包含定义，不包含 Run、密钥、聊天和原始 Trace。
常见敏感字段、凭据形式与越界路径会被拒绝；任意自然语言里的隐私不能保证自动识别，分享前仍须审阅。

本次自动化采用全新 F 盘测试档案、本机模型、受控 MCP、合成 Skill 和测试项目。
不导入正式或个人版密钥/聊天/角色，不发送收费模型和语音请求。Windows 安装测试使用原保护脚本，
先 DryRun，再保护原快捷方式与产品注册项，卸载并恢复；审核运行目录与原正式版分开。
