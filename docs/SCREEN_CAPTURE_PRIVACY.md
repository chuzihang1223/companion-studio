# 屏幕采集与隐私

默认不截图、不上传、不持久化。启用 UIA 窗口操作不自动启用预览；勾选窗口预览后，图片只在自有 worker、主进程和当前本地模块内存短期存在。约 8 秒过期清理；暂停、停止、接管、授权到期和应用关闭时撤销。不能保证运行时内存立即物理覆写，不宣称安全擦除。

## 允许范围

- `window`：只用 PrintWindow 获取用户选定的窗口。
- `region`：窗口内区域 `{x,y,width,height}`，整数像素，验证在窗口边界内。
- `display`：指定显示器的黑底画布，仅合成已授权窗口覆盖该显示器的部分；**不是完整桌面截图**，其他窗口区域保持黑色。

工作台当前提供窗口预览；区域和受限显示器模式通过严格工具/API 参数使用。捕获最大 4096 边长，发送前预览最大 2048 边长、PNG 不超过 2 MiB。最小化、保护状态、尺寸或映射异常会失败，不改用全屏抓取作为回退。

## 处理顺序

1. 固定窗口身份、授权与期限验证。
2. UIA 检查密码/敏感字段；扩展边界遮罩。
3. 检查 UIA 是否完整；存在未能处理的子树则拒绝图片。
4. PrintWindow 捕获授权范围，遮罩后编码。
5. 本地 OCR 隐私检查：自绘内容出现密钥/令牌/密码/银行卡等匹配文本时丢弃整个图片和 OCR；OCR 失败也不返回图片。
6. 再次检查窗口身份；只有通过检查的图像可进入本地预览。

这些是防护措施，不保证识别任意格式的秘密或图片中的所有个人信息。用户仍需选择不含私人资料的窗口。不可访问区域不能凭空完成脱敏。

## 外部模型

默认云端关闭。用户点击视觉分析时，原生确认框展示所选模型、目标窗口、一次图片传输及可能费用；随后重新采集。图片须通过本地隐私检查且仍在期限内。只发送该授权窗口图片，经原 ModelRoleRouter/LLMService；不把完整桌面发送到模型。

分析进入原 RuntimeRegistry 与 Trace，暂停/停止/接管/授权过期会取消该窗口所属的分析；取消不承诺撤回服务商已经收到的数据。Vision 不自动执行模型建议。

## 保存和日志

本阶段不提供截图证据持久化开关，不保存 PNG 到 SQLite/Trace/Checkpoint/日志。Trace 只记录随机身份、计数、时间、来源和验证结果。用户已允许输入的文本仍受原工作任务计划保存规则约束，不宣称所有输入都不落盘。独立 QA 图片仅来自项目原创无私人资料的 Fixture，并保存在隔离测试目录，不随公开源码导出。

Windows 捕获依据：[PrintWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-printwindow)、[GetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowdisplayaffinity)。这些 API 的限制不会被解释为隐私绝对保证。
