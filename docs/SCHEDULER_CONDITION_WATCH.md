# 受限条件监控

工作会话先选择项目，再在定时任务页授权当前项目元数据监控；或选择一个属于本会话的原
WorkflowRun 授权状态监控。来源默认 24 小时有效，可随时撤销，不自动续授权。

文件监控只读取路径元数据，不读取或执行文件正文：有界轮询、1000 个目录项、深度 4。
`.git`、依赖、缓存、临时文件、私密路径被排除。结果保存哈希和稳定时间，日志不存文件名正文。
变化包含新建、删除、修改和重命名；同一次保存的连续变化合并，等待 debounce 稳定后触发。
扫描不完整、拒绝访问、Junction 或符号链接会阻断来源，不伪造整目录删除事件。

Windows 使用实际 FILE_LIST_DIRECTORY 句柄且不共享 DELETE，阻止正在扫描的目录改名替换；
单纯 FILE_READ_ATTRIBUTES 不能提供这个保证。逐项重复核验 scope/private/reparse 属性。
这属于防御性 Windows 文件系统边界，不声称对恶意管理员、驱动或任意非 Windows 平台提供沙箱。

工作流条件只观察持久状态。初次轮询建立基线；False → True 且 cooldown 到期才触发。
持续 True 不会一直创建运行。文件稳定基线在触发后更新；冷却中的新变化在后续稳定后至多一次。
所有来源在排队、节点开始、审批等待后、每次实际工具调用和重试前重新验证。

来源中的文本、网页、MCP 返回或模型输出不能修改触发规则。
不提供全磁盘监控、任意脚本条件、私人应用状态抓取或自动外部事件订阅。
