# Companion Studio 0.1.2

本版本修复 Windows 记事本启动后没有可操作窗口的问题，并包含此前 0.1.1 的工程质量和 Windows 安装包交付改进。

## 修复与验证

- 用户请求打开 GUI 应用时不再传入隐藏窗口标志。该标志会使记事本等应用保留进程却隐藏窗口；后台后端及自动化辅助进程仍按原方式隐藏运行。
- 已发现的现代记事本即使只有 Windows 应用标识（AUMID）、没有 EXE 路径，也按准确的登记身份启动和观察，避免退回旧系统入口后无法识别真正的窗口。
- 保留窗口归属、聚焦、就绪验证、授权、取消和不重复启动规则，不以“进程存在”冒充启动成功。
- 新增 9 项启动回归，覆盖可见启动、参数隔离、创建失败、就绪验证、取消、现代记事本身份及相似名称拒绝；纳入 11 组 Electron 回归。
- 保留中文核心注释、类型、架构/开发文档、锁定依赖、CI 与受控 Windows 草稿构建流程。

原 v0.1.0、v0.1.1 标签保持不变，修复使用新的 v0.1.2 标签交付。

## 安装与使用

下载 `Companion-Studio-0.1.2-Setup.exe` 和 `SHA256SUMS.txt`，核对摘要后安装。程序包含 Electron、React 和 Python 后端，运行不要求用户安装 Python、Node.js 或 npm。建议目录结构为 `应用根目录\Release\installed`，用户资料在该根目录的 `UserData` 中，更新前先备份资料。

新安装默认使用通用助手。到「设置 → API」填写自己的 OpenAI-compatible 服务地址、模型和密钥后开始聊天；也可导入 JSON / PNG 角色卡或创建自定义角色。

## 限制与许可

- 安装器未进行发行者数字签名，Windows 可能显示未知发行者/信誉提示。
- 第三方桌面应用仍受客户端版本、系统、桌面解锁及焦点影响；本次修复不保证所有软件和环境均成功。
- Fish Audio、IndexTTS、本地模型和 Codex 编码需要用户自行配置相应服务、模型或账号，部分服务可能计费。
- 不附带密钥、聊天、角色图片/声音、参考音频或用户模型；原创代码采用 MIT，第三方声明、许可和必要对应源码随包保留。
